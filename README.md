# A* Algorithm Implementation

This project is an implementation of the A* Algorithm for pathfinding in a graph and solving the 8 puzzle problem. This was completed as an Honors Contract for the IT 279: Algorithms and Data Structures course at Illinois State University. As part of the course, I researched an unfamiliar algorithm and wrote an essay explaining its benefits and drawbacks, when to use it, and how to implement it. This project took that a step further by actually implementing the algorithm myself.

## Features of the project include:
Point-to-point pathfinding: The A* algorithm utilizes Euclidean distance as a heuristic to quickly find the shortest path between two points.

8 puzzle solutions: The A* algorithm uses the sum of the Manhattan distance of each numbers location compared to its goal location as a heuristic to find the shortest solution.

Testing data: The repository includes a testing graph and testing functions for point-to-point pathfinding and the 8 puzzle problem to verify correct functionality.
